# Scientific vector appearance

## Reference fidelity

Preserve source layout, scientific objects, relationships, labels, line weights and colors unless redesign is requested. Do not impose a stock icon library, small palette or generic silhouette on a detailed reference. Directly author important contours, interfaces, internal structure and negative spaces.

Flag suspected scientific issues without silently changing source meaning. Preserve ambiguity rather than inventing a claim.

## Illustrator-native profile

- Editable Bézier paths, shapes and live text.
- Native linear/radial gradients and controlled opacity for tissue, liquid, material and highlights. Keep natural softness; do not harden every edge for apparent sharpness.
- Separate paths for fine fibres, bonds and curves; check endings, joins and dash phase.
- Vector-only clipping for insets is permitted; inspect the imported boundary. Use SVG 1.1, not Tiny.
- No raster textures, blur filters, embedded source pictures or pixel-rectangle substitutes. Meshes and other unsupported effects require a separately supported workflow.

## Portable profile

The portable PowerPoint workflow needs solid fills and supported opacity. Derive its geometry from the same measured scene. If converting a gradient to solid editable shapes materially changes appearance, disclose it and obtain agreement. Do not embed a raster to hide incompatibility.

## Text and review

Use an available matching font; Arial is a fallback, not a promised source-font match. Keep live text. Check widths, baseline, line breaks, symbols, weight, alignment and object-label gaps. Avoid duplicated labels and broad patches hiding nearby content.

New designs may use a restrained biological illustration style. In reference reconstruction, user review determines stylistic acceptability; it does not authorize hidden technical errors or changed scientific meaning.
